A disciplina trata sobre os fundamentos de desenvolvimento mobile, tipos de dispositivos e seus sistemas operacionais.

Os dispositivos operam em diversos sistemas operacionais, sendo os princiapis Android e iOs, tendo cada uma suas próprias diretrizes, linguagens e ferramentas.
A criação de apps pode seguir diferentes abordagens, sendo elas: Desenvolvimento Nativo, Desenvolvimento Híbrido e Desenvolvimento Multiplataforma.

O desenvolvimento nativo são os aplicativos que utilizam da linguagem oficial de cada sistema operacional. Android costuma utilizar Java ou Kotlin, enquanto iOs usa Swift ou Objective-C. Essa abordagem funciona por oferecer um desempenho maior, melhor integração e uma experiencia mais fluida ao usuario.

Desenvolvimento híbrido são desenvolvidos usando tecnologias web com frameworks como Apache Cordova, Ionic e Framework7 sendo os mais utilizados. Embora seja mais rapido e barato que o desenvolvimento nativo, existem lmitações em relação ao desempenho e funcionalidades de sistemas.

Desenvolvimento multiplataforma é aqueles que são desenvolvidos com uma base unica de código, sendo utilizada tanto no Android quanto no iOs. Tecnologias como Flutter, React Native e Xamarin permitem que a criação de apps sejam efecientes e com desempenho proximo ao nativo, reduzindo o tempo com custos e desenvolvimento.

Etapas de planejamento para este tipo de desenvolvimento:

Planejar e Definir requisitos: Definir objetivos do aplicativo, funcções, publico alvo e requisitos técnicos.

Design da Interface e UX: Crucial para o sucesso do App, utilizando ferramentas como Figmas, Adobe XD e Sketch para criar protótipos.

Desenvolvimento: Utilizar liguagens e frameworks adequados de acordo com a escolha de desenvolvimento.

Testes e Depuração: Conferir se o aplicativos está livre de bugs e funcionando corretamente.

Publicar e distribuir: Enviados para lojas oficiais como Google Play e App Store onde cada um é aprovado de acordo com as diretrizes da plataforma.

Manutenção e Atualização: Corrigir erros e atulizar o aplicativo para melhorar a funcionalidades e manter a compatiblidade com novas versões.

React Native é um framework de desenvolvimento mobile criado pelo Facebook (Meta) que permite aplicativos para Android e iOs serem gerados utilizando JS e React, sendo um desenvolvimento multiplataforma com código unico. É possível reutilizar componentes e acessar APIs nativas do dispositivo, otimizando a experiência do usuario. A reutilização de componentes e o recurso de hot reload facilitam o desenvolvimento agil, sendo amplamente adotado pelas empresas.

Expo Dev é uma plataforma que facilita o desenvolvimento de Apps Mobile utilizando React Native, tirando a necessidade de configuração de ambientes nativos. O Expo Dev oferece ferramentes e SDKs que permitem criar, testar e publicar aplicativos, sendo possível visualizar mudanças em tempo real no celular sem precisar recompliar.
