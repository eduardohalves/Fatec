# Exercícios de classificação binária e regressão linear

## Exercicio 1
Exercício 1
Com base no conjunto de dados de imagens de caracteres manuscritos do MNIST e nos exemplos apresentados em sala de aula, programe um classificador binário em Python para identificar o caractere '3'.  

Para tanto, divida o conjunto de dados entre treinamento e teste. Ao final, avalie o desempenho do algoritmo apresentando a matriz de confusão para o conjunto de testes e as taxas de precisão, acurácia e sensibilidade (recall).  

## Exercício 2
Utilizando o conjunto de dados da planilha em anexo, que correlaciona o peso de veículos com sua eficiência (consumo de combustível em km/l), programa um modelo de regressão linear em Python para ajustando-o ao conjunto de dados.  

Informe os parâmetros obtidos após o treinamento do modelo (i.e. coeficiente linear e coeficiente angular da reta).  

Utilize o algoritmo para predizer qual a eficiência de um veículo com peso de 1.300 kg.
